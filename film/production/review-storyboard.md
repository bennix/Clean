# 独立分镜评审

结论：**再改一轮**。

审查范围仅限 brief.md、storyboard.md，以及 ContentView.swift、DiskService.swift。未评判实际成片、素材或其他事实文件。本轮分镜有可用的主线，但存在一项会直接误导用户的事实错误，以及尚不足以交付动画制作的动作与交接定义。

| 严重程度 | 帧号 | 具体问题与必须修改 |
|---|---|---|
| 阻断 | 360–539 | 点击“全选”后只勾缓存、备份保持未选，是错误演示。ContentView.swift:300 把可选项目全部加入 selected；此处没有敏感数据例外。必须画出全选后备份也被勾选，再由光标手动取消备份勾选，随后明确停留“手动取消勾选 · 保留设备备份”。不能仅改旁白或角落小字。brief 的“备份保持未选”和 storyboard 的“示例备份默认不选”也必须同步改为这一操作链。 |
| 高 | 540–719 | 一段三秒承载审查文字、两个运行中策略、选择、确认、删除结果及永久删除提示，无法可靠读清。尤其 600 选择至 660 确认只有一秒，确认至出镜又只有一秒。把“普通缓存永久删除”提前放到审查出现时，留出静止阅读时间；减少别处功能展示，为取消备份和审查判断让时间。 |
| 高 | 600–719 | 选择“退出相关应用后清理”后，不能不加条件地让全部缓存行消失。DiskService.swift:39–86 仅正常退出相关第三方桌面应用及 Safari，最多等待八秒，仍在运行及相关开发任务会跳过。演示需指定已退出的样例、保留一条“仍在运行 · 已跳过”，或将成功结果明确限定为这些样例项目；主阅读层显示“先保存工作 · 正常退出，未退出则跳过”。镜头压缩等待允许，但需有演示时间压缩标识。 |
| 高 | 180–359 | 240 帧即完成扫描音，距此镜开始只有一秒；列表“依次显现”和“扫描线到达”没有逐项完成帧。若完成音先于最后结果，会造成操作无结果或错时。写明各行出现、扫描完成文字、完成音的共同完成节点；稳定展示后再进入选择。 |

| 中 | 720–899 | treemap 点击进入文件夹有代码依据（ContentView.swift:522 起的 action），但“内部块展开”是演示动效，不能表现为原生已有动画。把点击、路径变化、下级内容替换写清，保留“界面重建 · 示例数据”。当前未指定点击哪个文件夹及下层名称，无法核验空间叙事。 |
| 中 | 900–1079 | CPU、内存、网络、温度四项加曲线和主文案，在三秒里只能形成概览，难以辨认全部读数。限定一个主要变化，其余作稳定背景；温度数据的可用性与刷新机制无法仅凭这两份源码核实，不能把四项必然实时可用当成已验证事实。 |

## 可以保留的内容

24 秒总帧数计算正确，结尾 180 帧品牌与网址停留可用。“普通缓存永久删除”与敏感项目移入废纸篓的区分有源码依据（ContentView.swift:337；DiskService.swift:89–90）。“所有删除均需确认”是界面已有表述（ContentView.swift:67）。不承诺释放多少 GB、允许保留备份、将演示数据标清，方向正确。

## 下一轮通过条件

1. 在帧表中明确画出“全选 → 备份被选中 → 手动取消备份 → 审查确认 → 备份保留”，每一步都有操作及可见结果。
2. 给风险文字安排足够静止阅读时间，明确成功和跳过结果，不暗示能自动退出所有进程或瞬间完成真实扫描。
3. 补齐每个边界的对象身份、起止状态和交接帧；统一锚点仅是约束，不能替代动作设计。
4. 为 24 秒节奏减项，并给出手机完整画幅下的主信息可读标准。

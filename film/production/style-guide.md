# 风格手册

六色：纸白 #f5f7f4；深绿 #14201c；App 深底 #13171d（SwiftUI 0.075/0.09/0.115 四舍五入）；薄荷 #c7e6b7；青绿 #4a9d83；纯白 #ffffff。颜色来自官网及 App，使用原样六色，透明度仅用于非文字层。

字体：本地固定 NotoSansSC 可变字体，OFL 许可一并提交；中文系统字体无法重新分发，因此选外观相近的开放字体，确保跨机器渲染一致。主标题 84–108 / 650，UI 32–46 / 500，标识 26 / 500。Clean 名称来自产品，图标直接使用源工程1024 PNG，无 SVG 源、不追摹。

质感：纸面和原生 App 圆角，不使用装饰颗粒和镜头眩光。深色框带克制投影；浅色细边框。真实 UI 按功能重建成可独立动画的行、按钮、路径、图表。

动效：四次方缓出进场；响应过冲后回稳；次级逐行错开7帧；每次交接24帧，中心锚点A=(1320,540)。快转场使用轻微方向模糊，内容停留时2px呼吸，曲线继续滚动。所有位置来自帧数，不使用定时器或未设种子的随机数。

声音：120BPM，C/A/F/G和声，玻璃键音、短低音与极轻的节拍。点击为高频短音；过场为中频风声；确认为三音收束。混音 -14 LUFS，TP≤-1dBTP，音效整体低于音乐；无人声、不仿艺人。

正式版镜头推进：非HUD内容共享坐标组，按每镜时长做1.01→1.05倍检查推进与20px横移，速度用正弦调制；光标和目标同组，顶部/底部文字固定。用实际视频freezedetect -60dB、0.5秒复核，无近冻结段。

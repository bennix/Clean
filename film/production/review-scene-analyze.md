# 磁盘分析独立评审

评审对象：`CleanMac/film/out/review-v1.mp4`，仅 18.00–21.00 秒，960×540、60 fps。结论：**再改一轮**，存在一项明确的文字对比度不达标。

## 方法

自行用 ffmpeg 抽取 18.00–20.80 秒每 0.20 秒画面，并对 18.70–19.65 秒每 0.05 秒加密抽帧；另查看 19.00 秒原尺寸帧。联系表位于 `/tmp/cleanmac-analyze-review/coarse.jpg`、`dense.jpg`，原尺寸证据 `frame19.png`。同步核对 `facts.json` 的 analyze 主张和当前配色定义；判断以视频画面为主。

## 问题

- **P1 / 18.00–18.95、19.00–20.80 秒：正常大小白字在青绿色块上对比度不足。** 前段 Downloads、后段 Design 使用白字与约 #4a9d83 背景，理论对比度 **3.26:1**，低于要求的 4.5:1。19.00 秒解码帧该块主要像素为 RGB(72,157,130)，与定义接近，压缩没有消除问题。输出视频中文字约 16 px，亦不能按大字 3:1 处理。建议把这两个标签改为深色墨绿，或把色块背景压暗后复测。

## 核对通过

- **18.70–18.95 秒 / 光标命中：** 光标尖端位于 Projects 大色块内部（视频坐标约 x543、y302），远离邻块及边界；不是点在空白或 Downloads 上。
- **19.00 秒 / 路径与内容：** 18.95 秒仍为 `~/`、Projects / Downloads / Documents；19.00 秒首次加密样本同时显示标题 `分析 · ~/Projects`、路径 `~/Projects` 和 Web / Design / Tools。没有观察到路径先变而内容滞后的画面。光标按下缩小与切换同刻可见，动作因果成立。此结论精度为加密采样间隔 0.05 秒。
- **18.00–20.80 秒 / 排版：** 主标题、副文案、窗口、路径、块内标签及底部声明均无文字相撞或截断。Projects / Web 的深字浅底、Documents / Tools 的白字深底、正文和路径均明显满足 4.5:1；例外如上。
- **事实：** “逐层看清磁盘占用”“点进文件夹，继续往里看”与 facts.json 所引 README 的“目录逐层大小分析、按占用面积生成 treemap”一致。`~/Projects` 与子目录是演示内容，底部“界面重建 · 示例数据 · 演示节奏”持续披露；未出现回收容量、扫描速度或真实测量暗示。

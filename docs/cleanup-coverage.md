# Clean 与 Mole 的清理覆盖

Clean 1.1.0 根据 Mole 的公开缓存位置补充独立 Swift 扫描规则；未复制其 GPL shell 实现。对比参考 [Mole 源码](https://github.com/tw93/mole/tree/3041d86cc0d4244377940f035b261bdff4e13fea/lib/clean)。

| 范围 | Clean 1.1.0 |
| --- | --- |
| 用户缓存、日志、Xcode 构建缓存 | 扫描，包括隐藏项 |
| npm、Bun、Yarn、pip、uv、Poetry、Gradle、Cargo 下载缓存 | 扫描已知位置，运行中的工具保守跳过 |
| 沙盒容器、共享容器缓存 | 只扫描明确的 Caches 目录；共享缓存需审查并移入废纸篓 |
| Chromium 浏览器 Profile、常见 Electron 应用 | 只扫描已知缓存子目录 |
| Xcode 归档、设备支持、iOS 备份 | 单独标识个人数据，确认后移入废纸篓 |
| 废纸篓、下载残留、项目 node_modules、Docker prune | 不自动并入缓存清理 |
| 系统级缓存、快照、模型、凭据与浏览器历史 | 不自动删除 |

Mole 再次扫描仍有结果，不一定表示删除失败：两者覆盖不同；应用会重新生成缓存；运行中项目会跳过；权限可能限制读取或删除；移入废纸篓仍占空间。Clean 的处理结果会列出运行中跳过、失败以及删除后仍存在或重新生成的路径。

普通缓存永久删除；个人数据与共享容器缓存移入废纸篓。所有处理先展示路径与大小并等待确认。全选只选当前搜索结果中完整、符合路径边界的项目，分析页选中项只移入废纸篓。测试只使用临时样本，不清理真实用户数据。
